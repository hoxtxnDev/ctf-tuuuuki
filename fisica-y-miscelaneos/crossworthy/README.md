# Desafío CTF: `crossworthy` — Crossworthy

## 1. Introducción
Crucigrama temático de ciberseguridad distribuido en formatos HTML interactivo y PNG.
- **Categoría:** Misceláneo

## 2. Objetivo
Reforzar terminología técnica de seguridad informática, cultura hacker y vulnerabilidades mediante la resolución de pistas cruzadas.

## 3. Requisitos
- Navegador web o visor de imágenes.

## 4. Instrucciones de ejecución
1. Este desafío se resuelve de forma estática/fuera de línea o presencial (no requiere levantar un contenedor de servicio).
2. Archivos distribuidos al participante: `distfiles/crossworthy2025.html`, `distfiles/crossworthy2025.png`.

## 5. Metodología de resolución
Resolver las pistas horizontales y verticales del crucigrama en `distfiles/crossworthy2025.html` hasta completar la casilla 66 horizontal (66 Across) y envolver el término en el formato de flag.

## 6. Sistema de puntuación
- **Puntaje base del desafío:** `1000` puntos (configurado en `metadata.yml`).
- El desafío otorga el puntaje al validar la cadena de respuesta exacta en la plataforma del CTF.

## 7. Formato de flags
La flag de este desafío sigue el estándar institucional del laboratorio:
```text
DUOC{palabra_clave_XXXXX}
```

## 8. Consideraciones de seguridad
- Este ejercicio debe ejecutarse exclusivamente dentro del entorno de laboratorio aislado o sobre los archivos provistos en `distfiles/`.
- No utilices las técnicas estudiadas fuera de entornos educativos expresamente autorizados.
