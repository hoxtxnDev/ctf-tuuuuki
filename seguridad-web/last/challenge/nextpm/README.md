Este es un proyecto de [Next.js](https://nextjs.org) inicializado con [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) para la aplicación NextPM del desafío `last`.

## Primeros pasos

Primero, inicia el servidor de desarrollo:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.

Puedes editar la página principal modificando `app/page.tsx`. La vista se actualiza automáticamente al guardar los cambios.
